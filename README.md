# Space Habitat

A personal hobby project to study rotating space habitats built from asteroid materials, with space for people and nature, and factories to build more habitats.

The repository contains design notes and numerical models covering structure, materials, power, food, heat, and construction.

This is a vibe coding experiment: Claude Opus 5.5 generates the code and GPT 6.1 reviews it, under my direction. The models help check the assumptions, but do not prove that the design would work.

See [notes.md](notes.md) for the design and [plan.md](plan.md) for the work in progress.
